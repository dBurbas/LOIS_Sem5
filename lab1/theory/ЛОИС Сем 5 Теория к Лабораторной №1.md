## Мощность нечеткого множества
---
**Нечёткая мощность** — это обобщение числа элементов обычного множества на случай, когда каждый элемент принадлежит множеству не полностью, а со степенью $\mu_A(x)\in[0,1]$. Обычно её считают как **сумму степеней принадлежности** всех элементов конечного универсального множества.

Пусть
$$A = \mu_A(x_1)/x_1 + \mu_A(x_2)/x_2 + \dots + \mu_A(x_n)/x_n.$$

Тогда нечёткая *скалярная* мощность:
$$|A|_f = \sum_{x\in X}\mu_A(x).$$

В тесте именно *скалярная мощность*, хотя есть и другие определения, но на них пока пофиг.

Также под мощностью можно считать мощность [[#4. Ядро, носитель, высота, нормальность и субнормальность|носителя]]. 
Например для $A = \{<a,0>, <b, 0.5>, <c,0.3>, <d, 0.2>\}$ носитель будет $supp(A) = \{b,c,d\}$, здесь мощность носителя = 3.

## Операции с нечеткими множествами (объединение, пересечение, разность)
---
Заданы два множества для всех примеров.
$A = \{<a,0.2>,<b,0.7>, <c,1>, <d,0.4>\},\space B = \{<a,0.5>, <b, 0.3>, <c,0.6>, <d,0.8>\}$

### Объединение
**Объединение** (нечёткое «ИЛИ») — наименьшее множество, содержащее и A, и B.

$\mu_{A\overset{\sim}\cup B}(x)=\max(\mu_A(x),\mu_B(x))$

Пример: $A\overset{\sim}\cup B = \{<a,0.5>, <b,0.7>, <c,1>, <d,0.8>\}$ 

### Пересечение
**Пересечение** (нечёткое «И») — наибольшее множество, содержащееся и в A, и в B.

$\mu_{A\overset{\sim}\cap B}(x)=\min(\mu_A(x),\mu_B(x))$

Пример: $A \overset{\sim}\cap B = 0.2/a + 0.3/b + 0.6/c + 0.4/d.$ - то же самое что и $\{<a,0.2>, <b,0.3> ,...\}$ 

### **Дополнение** (отрицание):

$\mu_{\overline A}(x)=1-\mu_A(x)$

Пример: $\overline A = 0.8/a + 0.3/b + 0/c + 0.6/d.$

### **Разность и симметрическая разность**

**Разность** определяется как $A \overset{\sim}/ B = A\cap\overline B$.

Вообще формула такая:
$\mu_{A \overset{\sim}/ B}(x)=\min\{\mu_A(x),\,1-\mu_B(x)\}$

> **НО** у Ивашенко в теории: $\mu_{A \overset{\sim}/ B}(x)=\max\{0,\mu_A(x) -\mu_B(x)\}$

Пример: $1-B = 0.5/a + 0.7/b + 0.4/c + 0.2/d,$ поэтому $A\setminus B = 0.2/a + 0.7/b + 0.4/c + 0.2/d.$

**Симметрическая разность** — это модуль разности степеней принадлежности:

> Тут **сомнительная** инфа про симметрическую разность

$\mu_{A-B}(x)=\left|\mu_A(x)-\mu_B(x)\right|$

Пример: $A-B = 0.3/a + 0.4/b + 0.4/c + 0.4/d$

### **Дизъюнктивная сумма** 
Это $A\oplus B=(A\setminus B)\cup(B\setminus A)$. 

> Может быть это симметрическая разность

$\mu_{A\oplus B}(x)=\max\{\min\{\mu_A,1-\mu_B\},\ \min\{1-\mu_A,\mu_B\}\}$

## Нечеткие отношения
Нечёткое бинарное отношение — это нечёткое подмножество декартова произведения $X\times Y$, заданное функцией принадлежности $\mu_R:X\times Y\to[0,1]$.  Чёткое отношение даёт для пары только «да» или «нет» (0 или 1). Нечёткое даёт степень связи на всём интервале $[0,1]$.

Пример: $\{<<a,b>,0.2>,<<a,c>,0.5>,<<f,c>,0.1>\}$ 

## Нечеткая композиция нечетких отношений
Есть разные композиции
$$\text{max-min:}\quad \mu(x,z)=\max_y\min\{\mu_{R_1}(x,y),\,\mu_{R_2}(y,z)\}
\\
\text{max-prod:}\quad \mu(x,z)=\max_y\{\mu_{R_1}(x,y)\cdot\mu_{R_2}(y,z)\}
\\
\text{max-average:}\quad \mu(x,z)=\max_y\tfrac12\{\mu_{R_1}(x,y)+\mu_{R_2}(y,z)\}$$
Формула для теста:
$$\mu_{Q\circ R}(\chi,\lambda)=\max_{y}\Big(\min \big(\mu_Q(\chi,\gamma),\ \mu_R(\gamma,\lambda)\big)\Big)$$

Эту операцию также называют максиминной сверткой.  Вычисляют её так:
1. Для пары $(x,z)$ найти все $y$, для которых есть и $\langle x,y\rangle$ в $Q$, и $\langle y,z\rangle$ в $R$.
2. Для каждого такого y взять минимум двух степеней.
3. Из всех минимумов выбрать максимум.
4. Если ни одного пути нет, степень равна 0, и пара в результат не попадает.

Порядок важен: сначала $Q$, потом $R$, и средние элементы должны совпадать.
Исходные отношения:

$Q=\{\langle a,b\rangle:0.2,\ \langle a,c\rangle:0.5,\ \langle f,c\rangle:0.1\}$,
$R=\{\langle b,d\rangle:0.8,\ \langle c,d\rangle:0.4,\ \langle c,e\rangle:0.3\}$.

1) $\langle a,d\rangle$: путь через $b$ даёт $\min(0.2,0.8)=0.2$, путь через c даёт $\min(0.5,0.4)=0.4$. Берём $\max(0.2,0.4)=0.4$.
2) $\langle a,e\rangle$: через b пути нет, потому что $\langle b,e\rangle\notin R$. Через c получаем $\min(0.5,0.3)=0.3$.
3) $\langle f,d\rangle$: только через c, $\min(0.1,0.4)=0.1$
4) $\langle f,e\rangle:$ только через c, $\min(0.1,0.3)=0.1$
Итог:
$Q\circ R=\{\langle\langle a,d\rangle,0.4\rangle,\ \langle\langle a,e\rangle,0.3\rangle,\ \langle\langle f,d\rangle,0.1\rangle,\ \langle\langle f,e\rangle,0.1\rangle\}$

## Нечеткие операции с предикатами

### Нечеткая конъюнкция (t-норма / треугольная норма)
Формулы:
$$\text{Т-норма минимум (Заде): } T(a,b) = \min(a,b)$$
$$\text{Т-норма алгебраического произведения (a*b): } T(a,b) = a*b$$
$$\text{Т-норма граничного произведения (Лукасевич): } T(a,b) = \max(0,a+b-1)$$
$$\text{Т-норма драстического произведения: } T(a,b) = \begin{cases}\min(a,b), \text{если } max(a,b)=1 \\ \text{иначе }0\end{cases}$$
### Нечеткая дизъюнкция предикатов (конорма)
Формулы:
$$\text{Максимум: } S(a,b) = \max(a,b)$$
$$\text{Алгебраическая сумма: } S(a,b) = a+b-a*b$$
$$\text{Граничная сумма: } S(a,b) = \min(a+b,1)$$
$$\text{Драстическая сумма: } S(a,b) = \begin{cases}\max(a,b) , \text{если } \min(a,b)=0 \\ 1 \text{, иначе}\end{cases}$$

### Связь между нормой и конормой
Любую конорму (дизъюнкцию) можно получить из нормы (конъюнкции) и наоборот:
$$S(a,b) = 1- T(1-a,1-b)$$
$$T(a,b) = 1- S(1-a,1-b)$$

## Свойства t-норм
| Свойство            | Формула                                         | Суть                                          |
| ------------------- | ----------------------------------------------- | --------------------------------------------- |
| Коммутативность     | $$T(a,b)=T(b,a)$$                               | Порядок аргументов не важен                   |
| Ассоциативность     | $$T(a,T(b,c))=T(T(a,b),c)$$                     | Можно обобщить на любое число аргументов      |
| Монотонность        | $$a\le c,\ b\le d\Rightarrow T(a,b)\le T(c,d)$$ | Рост истинности частей не уменьшает результат |
| Нейтральный элемент | $$T(a,1)=a$$                                    | Полная истина не меняет значение              |
## Свойства t-конорм
| Свойство            | Формула                                         | Суть                                          |
| ------------------- | ----------------------------------------------- | --------------------------------------------- |
| Коммутативность     | $$S(a,b)=S(b,a)$$                               | Порядок аргументов не важен                   |
| Ассоциативность     | $$S(a,S(b,c))=S(S(a,b),c)$$                     | Можно обобщить на любое число аргументов      |
| Монотонность        | $$a\le c,\ b\le d\Rightarrow S(a,b)\le S(c,d)$$ | Рост истинности частей не уменьшает результат |
| Нейтральный элемент | $$S(a,0)=a$$                                    | Полная истина не меняет значение              |
**Следствия аксиом**

• **Граничные значения.** $T(a,0)=0 \text{ и } S(a,1)=1$. Из монотонности: $T(a,0)\le T(1,0)=0$. Суть: при полной лжи в одном аргументе конъюнкция тоже ложна, а при полной истине в одном аргументе дизъюнкция истинна.

• **Совпадение с классической логикой** на $\{0,1\}$: $T(1,1)=1, T(0,0)=T(0,1)=0; S(0,0)=0, S(0,1)=S(1,1)=1$.

• **Границы всех t-норм:** $T_D(a,b)\le T(a,b)\le\min(a,b)$. Минимум — самая сильная t-норма, а драстическое произведение — самая слабая.

• **Границы всех t-конорм:**$\max(a,b)\le S(a,b)\le S_D(a,b)$, где $S_D$ — драстическая сумма. Максимум — самая слабая t-конорма.

• **Монотонность по каждому аргументу** по отдельности следует из общей: $b\le c\Rightarrow T(a,b)\le T(a,c)$

## Двойственность

t-норма и t-конорма, связанные законом де Моргана, называются двойственными.  Со стандартным отрицанием:
$$S(a,b)=1-T(1-a,\,1-b),\qquad T(a,b)=1-S(1-a,\,1-b)$$

| t-норма                                | t-конорма                              |
| -------------------------------------- | -------------------------------------- |
| $$\min(a,b)$$                          | $$\max(a,b)$$                          |
| $$ab$$                                 | $$a+b -ab$$                            |
| $$\max(0,a+b-1)$$                      | $$\min(1,a+b)$$                        |
| $$\min(a,b) при \max(a,b)=1, иначе 0$$ | $$\max(a,b) при \min(a,b)=0, иначе 1$$ |
## Импликации
**Гёдель.** В литературе это импликация с кусочным определением:
$$I_G(a,b)=\begin{cases}1,& a\le b\\ b,& a>b\end{cases}$$

Она получается из t-нормы минимум как её остаточная (R-импликация): $\sup\{z:\min(a,z)\le b\}$.  
Суть: если посылка не сильнее следствия, то импликация истинна полностью, а иначе её значение ограничивается знаfdfdчением следствия.

**Лукасевич.**
$$I_L(a,b)=\min\{1,\ 1-a+b\}$$
**Вебер** 
$$I_V(a,b)=\begin{cases}1,& a < 1\\ b,& a=1\end{cases}$$

**Гоген**
$$I_G(a,b)=\begin{cases}1,& a\le b\\ \dfrac{b}{a},& a>b\end{cases}$$
## Modus-Ponens
B' получается через композицию A' и правила(импликации) A~>B
$$
\frac{A \rightsquigarrow B,\quad A'}{B'}, \qquad B' = A' \circ (A \rightsquigarrow B)
$$

Композиция:
$$
\mu_{R_1 \circ R_2}(x,z) = \sup_{y} T\big(\mu_{R_1}(x,y), \mu_{R_2}(y,z)\big)
$$

# Теория для лабораторной работы: Прямой нечёткий логический вывод

**Правило вывода:**
$$
\{A', A \rightsquigarrow B\} \;|\!\sim\; \{B'\}, \qquad B'(y) = \sup_x \big( A'(x)\ /\!\!\backslash\ (A(x) \rightsquigarrow B(y)) \big)
$$
где ($\sup$) — точная верхняя грань, , $/\!\!\backslash$ — треугольная норма — треугольная норма (нечёткая конъюнкция), ($\rightsquigarrow$) — нечёткая импликация, ($|\!\sim$) — нечёткая выводимость.

## 1. Нечёткое множество и функция принадлежности

Нечёткое множество обобщает обычное множество: принадлежность элемента измеряется степенью от 0 до 1, а не бинарно «да/нет». Для универсума ($X$) нечёткое множество ($A$) задаётся парами:
$$
A = \{(x, \mu_A(x)) \mid x \in X\}, \qquad \mu_A: X \to [0,1]
$$
где ($\mu_A(x)$) — **функция принадлежности** (membership function). В классической теории характеристическая функция принимает лишь значения 0 или 1; в нечёткой допускаются любые промежуточные степени.

### Формы задания функции принадлежности

**Треугольная** (параметры $(a \le b \le c)$):
$$
\mu(x; a,b,c) =
\begin{cases}
0, & x \le a \\
\dfrac{x-a}{b-a}, & a \le x \le b \\
\dfrac{c-x}{c-b}, & b \le x \le c \\
0, & x \ge c
\end{cases}
$$

**Трапецеидальная** (параметры ($a \le b \le c \le d$), появляется «плато» на ($[b,c]$)):
$$
\mu(x; a,b,c,d) =
\begin{cases}
0, & x \le a \\
\dfrac{x-a}{b-a}, & a \le x \le b \\
1, & b \le x \le c \\
\dfrac{d-x}{d-c}, & c \le x \le d \\
0, & x \ge d
\end{cases}
$$
Треугольная функция — частный случай трапецеидальной при ($b = c$).

**Гауссова** (параметры: центр ($c$), ширина ($\sigma$)):
$$
\mu(x; c, \sigma) = \exp\left(-\dfrac{(x-c)^2}{2\sigma^2}\right)
$$
Везде дифференцируема (нет «острых углов»), даёт плавную колоколообразную форму.

> **Для варианта 3.** По грамматике задания нечёткое множество задаётся не формулой, а явным списком пар `<элемент, степень>`. Поэтому параметрические формы (треугольная/трапецеидальная/гауссова) нужны лишь для понимания сути — в коде используется прямое табличное представление.

## 2. Универсальное множество (базовая переменная) и дискретизация

**Универсальное множество** (универсум, $(X)$ или $(U)$) — множество всех элементов, имеющих смысл в задаче; именно на нём определена функция принадлежности. **Нечёткая переменная** — тройка ($\langle a, X, A\rangle$): имя, универсум и нечёткое множество на нём. **Базовая переменная** — сама переменная ($x \in X$), пробегающая по универсуму (в отличие от лингвистической, принимающей качественные значения «низкий», «средний», «высокий»).

**Дискретизация** непрерывного универсума — замена интервала конечным набором точек ($X = \{x_1, \dots, x_n\}$) с шагом ($\Delta x$); чем меньше шаг, тем точнее приближение, но больше вычислений. Универсум может быть и изначально дискретным конечным множеством именованных элементов – тогда дискретизация не нужна.

> **Для варианта 3.** Универсум конечен и дискретен по построению (список имён элементов из файла базы знаний). Отдельного шага дискретизации не требуется. Нужно решить и задокументировать: элемент, отсутствующий в одном из множеств, разумно считать имеющим степень принадлежности 0.

## 3. Точная верхняя грань (супремум) и точная нижняя грань (инфимум)

**Супремум** ($\sup X$) — наименьшая из всех верхних граней множества, то есть наименьшее число ($M$), не меньшее любого элемента [cite:15][cite:16]:
1. ($\forall x \in X:\ x \le M$) (верхняя грань);
2. ($\forall \varepsilon > 0\ \exists x \in X:\ x > M - \varepsilon$) (наименьшая из верхних граней) [cite:16].

**Инфимум** ($\inf X$) — двойственное понятие: наибольшая из всех нижних граней, то есть наибольшее число ($m$), не большее любого элемента множества [cite:5][cite:8]:
1. ($\forall x \in X:\ m \le x$) (нижняя грань);
2. ($\forall \varepsilon > 0\ \exists x_\varepsilon \in X:\ x_\varepsilon < m + \varepsilon$) (наибольшая из нижних граней) [cite:14].

Супремум и инфимум обобщают максимум и минимум [cite:15]. **Отличие от max/min:** для конечного множества (или если грань достигается на элементе) ($\sup X = \max X$) и ($\inf X = \min X$). На непрерывном множестве грань может не достигаться: например, для открытого интервала $(0,1)$ максимума нет, но ($\sup = 1$), ($\inf = 0$).

> **Для варианта 3.** Универсум дискретен и конечен, поэтому ($\sup$) в формуле вывода всегда достигается и точно равен обычному максимуму по всем элементам — «для дискретного универсального множества супремум становится максимумом» [cite:9]. В коде ($\sup$) реализуется как перебор всех ($x$) с накоплением `std::max`.

## 4. Ядро, носитель, высота, нормальность и субнормальность

Эти понятия прямо нужны для ответа на вопросы 6.1–6.6 задания.

**Носитель** (суппорт, support) — чёткое подмножество универсума, где степень принадлежности строго положительна [cite:2][cite:9]:
$$
\operatorname{supp}(A) = \{x \in X \mid \mu_A(x) > 0\}
$$
Нечёткое множество пусто, если его носитель пуст [cite:9].

**Ядро** (core) — чёткое подмножество универсума, где степень принадлежности равна единице [cite:2][cite:9]:
$$
\operatorname{core}(A) = \{x \in X \mid \mu_A(x) = 1\}
$$


**Высота** — верхняя грань функции принадлежности [cite:9]:
$$
h(A) = \sup_{x \in X} \mu_A(x)
$$
Для дискретного универсума высота равна максимуму степеней принадлежности элементов [cite:9].

**Нормальное множество** — высота равна 1, то есть существует хотя бы один элемент со степенью принадлежности 1 [cite:2][cite:4]. Фундаментальная теорема: нечёткое множество нормально тогда и только тогда, когда его ядро непусто [cite:10].

**Субнормальное множество** — высота строго меньше 1 [cite:2][cite:4]. Ядро субнормального множества пусто [cite:9][cite:7]. Непустое субнормальное множество можно **нормализовать**, разделив все степени на высоту [cite:2][cite:4]:
$$
\mu'_A(x) = \frac{\mu_A(x)}{\sup_x \mu_A(x)}
$$

| Характеристика                      | Определение                 | Условие             |
| ----------------------------------- | --------------------------- | ------------------- |
| Носитель ($\operatorname{supp}(A)$) | ($\{x \mid \mu_A(x) > 0\}$) | сечение на 0-уровне |
| Ядро ($\operatorname{core}(A)$)     | ($\{x \mid \mu_A(x) = 1\}$) | сечение на 1-уровне |
| Высота ($h(A)$)                     | ($\sup_x \mu_A(x)$)         | —                   |
| Нормальное                          | ($h(A) = 1$)                | непустое ядро]      |
| Субнормальное                       | ($h(A) < 1$)                | пустое ядро         |

## 5. Треугольная норма (t-норма) и граничное произведение

**T-норма** — бинарная операция ($T: [0,1]^2 \to [0,1]$), обобщающая конъюнкцию «И» на нечёткие высказывания. Аксиомы (для любых ($a,b,c$)):
- **Коммутативность:** ($T(a,b) = T(b,a)$);
- **Ассоциативность:** ($T(a, T(b,c)) = T(T(a,b), c)$);
- **Монотонность:** если ($a \le c,\ b \le d),\text{то } (T(a,b) \le T(c,d)$);
- **Граничное условие:** ($T(a,1) = a) (\text{и обычно }(T(a,0) = 0)$).

Любая t-норма ограничена: ($T_{\text{драстич}}(a,b) \le T(a,b) \le \min(a,b)$), где ($\min$) — наибольшая (самая «мягкая») t-норма.

**Граничное произведение** (bounded product, t-норма Лукасевича) — по варианту 3:
$$
T(a,b) = \max(0,\; a + b - 1)
$$
Название отражает «срезание» границей 0. Проверка аксиом: коммутативность и монотонность очевидны; граничное условие ($T(a,1) = \max(0, a) = a$); ассоциативность даёт симметричный результат ($\max(0, a+b+c-2)$). Норма нильпотентна: при ($a + b < 1$) результат строго равен 0 (в отличие от ($\min$)).

```cpp
double t_norm(double a, double b) {
    return std::max(0.0, a + b - 1.0);
}
```

## 6. Нечёткая импликация и формула Лукасевича

**Нечёткая импликация**: ($I: [0,1]^2 \to [0,1]$) обобщает «если..., то...». Опирается на классическое ($a \to b \equiv \neg a \lor b$). Свойства: граничные условия ($I(0,0)=I(0,1)=I(1,1)=1,\ I(1,0)=0$); монотонность убывающая по посылке и возрастающая по заключению.

**Импликация Лукасевича** (при линейном отрицании ($\neg u = 1 - u$)) — по варианту 3:
$$
I_L(a,b) = \min(1,\; 1 - a + b)
$$
Здесь ($1 - a + b = \neg a + b$), а ($\min$) «срезает» результат до 1. Проверка на классических значениях даёт ($I_L(1,0)=0$) и ($I_L(0,0)=I_L(1,1)=I_L(0,1)=1$) — совпадение с булевой таблицей. Пример: ($I_L(0.8, 0.3) = \min(1, 0.5) = 0.5$).

```cpp
double implication(double a, double b) {
    return std::min(1.0, 1.0 - a + b);
}
```

> **Согласованность пары.** Граничное произведение и импликация Лукасевича образуют сопряжённую (резидуированную) пару: ($I_L(a,b) = \sup\{c \mid T(a,c) \le b\}$). Выбор в варианте 3 не случаен — система внутренне согласована и на значениях 0/1 сводится к булевой логике, что удобно для тестов.

## 7. Нечёткое отношение (правило A ~> B на X×Y)

Обычное бинарное отношение — подмножество ($R \subseteq X \times Y$). **Нечёткое отношение** обобщает его: паре ($(x,y)$) сопоставляется степень ($\mu_R(x,y) \in [0,1]$), показывающая силу связи. Формально это нечёткое подмножество декартова произведения.

Правило «если ($A$), то ($B$)» разворачивается в нечёткое отношение на ($X \times Y$):
$$
\mu_R(x,y) = \mu_{A \rightsquigarrow B}(x,y) = I\big(\mu_A(x), \mu_B(y)\big)
$$
В дискретном случае это матрица ($|X| \times |Y|$). Именно отношение ($R$) (а не ($A$) и ($B$) по отдельности) участвует в композиции с наблюдением ($A'$). В коде матрицу можно не хранить явно — достаточно вычислять ($I(A(x), B(y))$) «на лету».

<a, 0.1> ~> <b, 0.3> = $I_L(\mu_A(a),\mu_B{b}) = \min(1,\; 1 - 0.1 + 0.3)$ = 1

## 8. Композиционное правило вывода (sup-T композиция)

**Композиция** отношений ($R_1$) (на ($X \times Y$)) и ($R_2$) (на ($Y \times Z$)) через промежуточный универсум:
$$
\mu_{R_1 \circ R_2}(x,z) = \sup_{y} T\big(\mu_{R_1}(x,y), \mu_{R_2}(y,z)\big)
$$
При ($T = \min$) это классическая **max-min композиция** Заде; в общем случае — **sup-T композиция** с произвольной t-нормой. Интуиция: связь ($x$) с ($z$) существует, если есть хотя бы один промежуточный ($y$), связанный с обоими (супремум по путям, конъюнкция вдоль пути).

Формула вывода — частный случай (композиция множества ($A'$) с отношением ($R$)):
$$
B'(y) = \sup_x T\big(A'(x),\ I(A(x), B(y))\big)
$$
Итоговая рабочая формула варианта 3:
$$
B'(y) = \max_x \Big( \max\big(0,\ A'(x) + \min(1, 1 - A(x) + B(y)) - 1\big) \Big)
$$

**Алгоритм** (сложность ($O(|X|\cdot|Y|)$)): для каждого ($y$) инициализировать `sup=0`; перебрать все ($x$), вычислить импликацию, затем t-норму, обновить максимум; записать результат в ($B'(y)$).

```cpp
std::map<std::string,double> compose(
    const std::map<std::string,double>& A_prime,
    const std::map<std::string,double>& A,
    const std::map<std::string,double>& B) {
    std::map<std::string,double> B_prime;
    for (const auto& [y, b_y] : B) {
        double sup_val = 0.0;
        for (const auto& [x, ap_x] : A_prime) {
            double a_x = A.count(x) ? A.at(x) : 0.0;
            double impl = implication(a_x, b_y);
            sup_val = std::max(sup_val, t_norm(ap_x, impl));
        }
        B_prime[y] = sup_val;
    }
    return B_prime;
}
```

## 9. Обобщённое правило modus ponens (GMP / FMP) и прямой вывод

Классический **modus ponens:** из ($A \to B$) и ($A$) следует ($B$). **Обобщённое (нечёткое) правило modus ponens** допускает, что наблюдение ($A'$) лишь приближённо совпадает с посылкой ($A$):
$$
\frac{A \rightsquigarrow B,\quad A'}{B'}, \qquad B' = A' \circ (A \rightsquigarrow B)
$$
Тест на согласованность: при ($A' = A$) корректная реализация даёт ($B' = B$) (что соответствует вопросу 4 задания).

**Прямой вывод** (forward chaining) движется от посылки к заключению (от причины к следствию, data-driven) — это и есть FMP, требуемый в задании. **Обратный вывод** (backward chaining, абдукция) основан на нечётком modus tollens: из ($A \rightsquigarrow B$) и наблюдения ($B'$) восстанавливают ($A'$) (goal-driven); он требует закона контрапозиции и в задании не используется.

## 10. Нечёткая выводимость ($|\!\sim$) как обобщение логического следования

Классическое следование ($\Gamma \vdash \varphi$): заключение истинно во всех моделях посылок — результат строго бинарен. **Нечёткая выводимость** ($|\!\sim$) (теория приближённых рассуждений Заде) обобщает это: посылки и заключение — нечёткие множества, а результат — не доказанный факт, а вычислительная процедура (композиция через t-норму и импликацию), дающая наилучший приближённый ответ.

**Принцип выводимости** Заде: из «($X$) есть ($A$)» выводится «($X$) есть ($D$)», если ($A \subseteq D$) (($\mu_A(x) \le \mu_D(x)$)). Поэтому вывод ($B'$) обычно менее специфичен (более размыт), чем ($B$) — он честно отражает накопленную неопределённость. Символ ($|\!\sim$) специально отличается от ($\vdash$), подчёркивая вычислительный характер.

**Итеративность.** Применение GMP порождает новые факты, которые становятся посылками для новых применений правил. Процесс повторяется до **неподвижной точки** (новые выводимые факты совпадают с уже полученными) или до прерывания пользователем — это операционная реализация ($|\!\sim$) как транзитивного замыкания одношаговой процедуры GMP над базой знаний.

## 11. Ответы на вопросы 6.1–6.6 (ориентиры)

Вопросы задания касаются связи нормальности/субнормальности ($A'$), ($A$), ($B$) и результата ($B'$). Ключевые опоры для рассуждений:
- t-норма граничного произведения нильпотентна: ($T(a,b)=0$) при ($a+b<1$) — может «занулять» вклад и понижать высоту ($B'$);
- импликация Лукасевича ($I_L(a,b)=\min(1,1-a+b)$): при ($a=0$) даёт 1, при ($a>b$) — меньше 1;
- высота ($B'$) определяет его нормальность (($h(B')=1$) → нормальное, ($h(B')<1$) → субнормальное);
- тождество ($B'=B$) достигается при согласованности ($A'$) с посылкой ($A$) (для нормальных множеств — при ($A'=A$), связано с тестом GMP из раздела 9).

Конкретные ответы следует получить экспериментально на реализованной программе (порядок выполнения работы, п. 5–6), подставляя нормальные и субнормальные ($A'$) и наблюдая высоту ($B'$).
